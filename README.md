# Cityflo Data Scientist Take-Home

The supplied CSV files are in [`data/`](data/). All analysis and submission materials are in [`submission/`](submission/), including the assignment brief, code, tests, decision record, and steering ledger.

## Run

```powershell
python -m pip install -r submission/requirements.txt
python submission/analyze.py
python -m unittest discover -s submission -v
```

See [`submission/README.md`](submission/README.md) for details.
